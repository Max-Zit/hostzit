Prvi koraci

HostZit je kontrolni panel za web hosting koji radi na vašem serveru. U admin panelu upravljate serverom (korisnici, paketi, DNS, ažuriranja), a svaki korisnik u korisničkom panelu uređuje svoje sajtove, domene, baze, fajlove i WordPress. Slobodan je softver pod licencom AGPL-3.0.

Šta HostZit radi

OblastŠta dobijate
NaloziSvaki korisnik je izolovan nalog sa svojim ograničenjima; deljeni hosting za mnogo korisnika ili dedikovan server za jednog. Korisnici i paketi
Sajtovinginx i PHP-FPM, besplatni HTTPS sertifikati, HTTP/2 i HTTP/3, preusmeravanja, keš stranica po sajtu. Sajtovi
DNSAutoritativni name serveri sa editorom i DNSSEC-om. Domeni i DNS
WordPressInstalacija, prijava jednim klikom, ažuriranja sa snimcima, staging kopije. WordPress
BezbednostIzolacija naloga, firewall, ograničenja pokušaja, skeniranje malvera, prijava u dva koraka. Izolacija i bezbednost
NaplataREST API za vaš sistem naplate ili portal. REST API

Kako radi

  • hostzit-server služi oba panela i API. Radi kao neprivilegovani korisnik hostzit: admin panel na portu 8442, korisnički na 8443.
  • hostzit-helper je jedini deo koji radi kao root. Prihvata kratak spisak proverenih operacija od panela i piše konfiguraciju nginx-a, PHP-a, DNS-a i naloga iz sopstvenih šablona.
  • Svaka promena se upisuje u audit log koji se ne može neprimetno menjati.

Prvi koraci

  1. Instalirajte HostZit na nov Debian server — Instalacija servera.
  2. Napravite prvog administratora pomoću setup tokena koji instalacija prikaže i podesite prijavu u dva koraka.
  3. Otvorite Podešavanja → Hosting: ime servera, IP adresa, name serveri i Let's Encrypt.
  4. Napravite paket (prostor, CPU, memorija, sajtovi, baze) u Paketima.
  5. Napravite prvog korisnika sa domenom u Korisnicima ili uvezite cPanel backup u Uvozu.
