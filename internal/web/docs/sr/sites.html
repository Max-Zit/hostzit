Sajtovi, PHP i keš stranica

Sajt je domen (sa www i drugim aliasima) koji se služi iz foldera naloga, podrazumevano ~/sites/DOMEN/public.

Nov sajt

Unesite domen u Sajtovi → Nov sajt. HostZit pravi folder sa prvom stranicom, konfiguraciju web servera i, ako želite, DNS zonu. Usmerite domen na server (ili postavite name servere kod registra); besplatan Let's Encrypt sertifikat stiže sam i obnavlja se 30 dana pre isteka.

Podešavanja

  • Verzija PHP-a po sajtu.
  • Glavna adresa: sa ili bez www; druga se preusmerava.
  • Preusmeri HTTP na HTTPS i HSTS.
  • Preusmeravanja: jedno po redu, npr. /staro /novo 301.
  • Aliasi: drugi domeni koji prikazuju isti sajt.
  • Sopstveni sertifikat: nalepite sertifikat i ključ umesto Let's Encrypt-a.

Keš stranica

Kada je keš stranica uključen, web server čuva gotove stranice i odgovara posetiocima bez pokretanja PHP-a: stranice su mnogo brže, a server ima daleko manje posla. Prijavljeni korisnici, WordPress admin, autori komentara, korpe, forme (POST) i adrese sa upitom uvek dobijaju sveže stranice. Stranice se čuvaju koliko izaberete; Očisti keš briše sve odjednom (posle izmene dizajna ili sadržaja). Zaglavlje odgovora X-Cache pokazuje HIT, MISS ili BYPASS.

Pristup i zaštita

  • Web aplikacioni firewall (ModSecurity sa OWASP Core Rule Set-om, podešen za WordPress) blokira SQL injection, cross-site scripting i skenere.
  • Samo ove adrese / Blokirane adrese: IP pravila za ceo sajt.
  • Zaštita od hotlinkovanja: drugi sajtovi ne mogu da ugrađuju vaše slike i video.
  • Folderi pod lozinkom: posetioci foldera moraju da unesu korisničko ime i lozinku.

Logovi

Logovi prikazuju poslednje posete i greške sajta; PHP greške su u ~/logs/php-error.log.
