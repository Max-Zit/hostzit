REST API za naplatu

Vaš sistem naplate ili portal pravi, suspenduje i gasi naloge, menja pakete i otvara korisnički panel preko API-ja admin panela (port 8442).

Tokeni

Napravite token u Moj nalog → API tokeni i izaberite šta sme: customers:read, customers:write, usage:read, sso:create, dns:mail (EmailZit). Šaljite ga kao Authorization: Bearer hzt_….

Pravila

  • JSON, vreme u RFC 3339 UTC; liste sa ?limit= i ?cursor=, odgovor {"items": […], "next_cursor": "…"}.
  • Greške: {"error": {"code": "invalid", "message": "…", "field": "domain"}}.
  • Idempotency-Key uz POST: ponovljen zahtev vraća prvi odgovor (24 sata).
  • Spori poslovi odgovaraju sa 202 i job_id; pratite ih na GET /api/v1/jobs/{id}.
  • {id} je UUID korisnika, ext: + vaš id, ili ime naloga.

Lokalni socket za EmailZit

Kada EmailZit radi na istom serveru, DNS deo API-ja (GET /api/v1/domains/{domain}, GET|PUT|DELETE /api/v1/dns/zones/{zone}/owned/{owner}) može da koristi preko Unix socketa /run/hostzit-api/api.sock bez tokena. HostZit svaku konekciju proverava po korisniku procesa koji poziva: odgovara samo root-u i servisnom korisniku emailzit.
