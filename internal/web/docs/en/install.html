Installing the server

HostZit runs on Debian 13 (or 12) with systemd and cgroups v2. Use a fresh server: the installer configures nginx, PHP, MariaDB, PowerDNS and SSH for hosting.

Requirements

  • 2 CPU cores and 2 GB of memory for a few accounts; for many WordPress sites plan about 10–20 MB of memory per account plus the visitors' PHP requests. 500 accounts fit on a server with 16–32 GB.
  • A public IPv4 address (IPv6 optional) and a host name such as host1.example.com.
  • For DNS hosting: two name server names (ns1, ns2) with glue records at the registrar of your domain.
  • User quotas on the file system of /home (ext4 or XFS) so disk limits are enforced; the installer switches them on for ext4.

Install

curl -fsSL https://github.com/Max-Zit/hostzit/releases/latest/download/install.sh | sudo bash

The installer checks the signature of the release, installs the packages, creates the database and prints the address of the admin panel and the setup token. Options: --version X.Y.Z, --php "8.3 8.4", --no-dns.

Dedicated server

For one customer only, choose Dedicated server under Settings → Hosting. Package limits are then not applied; the isolation and security stay the same.

Appliance (VM image or ISO)

Instead of the installer you can start from the HostZit appliance: Debian 13 with everything HostZit needs, set up by itself at the first start. Each release has

  • hostzit-appliance-X.ova for VMware ESXi, Workstation and VirtualBox,
  • hostzit-appliance-X.qcow2 for Proxmox VE and KVM,
  • hostzit-appliance-X.vhdx for Hyper-V (generation 1),
  • hostzit-appliance-X.iso for physical servers and new VMs (erases the first disk).

The VM disk is 32 GB; enlarge it in the virtualization host whenever you like, the appliance grows its file system at the next start. After the first start (a few minutes) the screen of the VM shows the addresses of both panels and the setup token.

On the server's screen, sign in as hzadmin (first password hostzit, it must be changed): a menu sets the network, host name and time zone. In the admin panel the same is under Settings → System, together with restart and shut down. A static address whose gateway does not answer is not kept: the previous settings come back by themselves.
