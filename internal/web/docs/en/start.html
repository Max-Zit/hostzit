Getting started

HostZit is a self-hosted web hosting control panel. The admin panel runs the server (customers, packages, DNS, updates); every customer manages their own websites, domains, databases, files and WordPress in the customer panel. It is free software under the AGPL-3.0.

What HostZit does

AreaWhat you get
AccountsEach customer is an isolated account with its own limits; shared hosting for many customers or a dedicated server for one. Customers and packages
Websitesnginx and PHP-FPM, free HTTPS certificates, HTTP/2 and HTTP/3, redirects, a page cache per site. Websites
DNSAuthoritative name servers with an editor and DNSSEC. Domains and DNS
WordPressInstall, one-click sign-in, updates with snapshots, staging copies. WordPress
SecurityIsolation between accounts, firewall, rate limits, malware scans, two-factor sign-in. Isolation and security
BillingA REST API for your billing system or portal. REST API

How it works

  • hostzit-server serves both panels and the API. It runs as the unprivileged user hostzit: the admin panel on port 8442, the customer panel on 8443.
  • hostzit-helper is the only part that runs as root. It accepts a short list of checked operations from the panel and writes the configuration of nginx, PHP, DNS and the accounts from its own templates.
  • Every change is written to the tamper-evident audit log.

First steps

  1. Install HostZit on a fresh Debian server — Installing the server.
  2. Create the first administrator with the setup token the installer shows, and set up two-factor sign-in.
  3. Open Settings → Hosting: the server name, its IP address, the name servers and Let's Encrypt.
  4. Create a package (disk space, CPU, memory, websites, databases) under Packages.
  5. Create the first customer with a domain under Customers, or import a cPanel backup under Import.
