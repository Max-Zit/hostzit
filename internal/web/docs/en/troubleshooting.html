Troubleshooting and FAQ

The website has no certificate

The domain (and www) must point to the server's address in DNS, port 80 must be reachable, and Let's Encrypt must be on under Settings → Hosting. The website page shows the last error; HostZit tries again every few hours.

A website shows 502 or 503

502: PHP of the account is not running — use Set up again on the customer page; the account may be suspended or out of memory (see Usage). 503 with "temporarily unavailable": the account is suspended.

The website is slow

Switch on the page cache, check the PHP workers and memory of the package and the CPU graph under Usage. A limit that is reached slows the account down instead of the whole server.

Mail from a website does not arrive

Look at the queue under Security (customer) — messages above the hourly limit wait; check that a relay is set in Settings → Notifications with "Mail from websites" on.

I locked myself out

On the server: hostzit-server --unblock-ip all and hostzit-server --reset-allowlist, then restart the service. A lost authenticator: another administrator resets the second factor; with only one administrator, use a recovery code.

Logs

Panel: /var/lib/hostzit/panel/logs/server.log; helper: /var/log/hostzit/helper.log; websites: /var/log/hostzit/sites/ID/; firewall: /var/log/hostzit/modsec_audit.log.
