WordPress

The WordPress toolkit installs and looks after WordPress sites. It uses WP-CLI, which runs as your account in your own environment.

Install

WordPress → Install WordPress: choose the website, the title, the administrator name (not admin) and e-mail, and the language. HostZit makes a database and user, downloads WordPress, writes wp-config.php (readable only by your account), switches off the file editor in wp-admin and sets up pretty links. Sites uploaded by hand or imported from cPanel are found with Find existing installs.

Sign in

Open wp-admin signs you in as the administrator with a one-time link (valid 60 seconds, once).

Updates and snapshots

Check now lists new versions of WordPress, plugins and themes; Update everything first makes a snapshot (files and database in ~/backups), then updates and clears the page cache. Restore puts a snapshot back. Automatic updates run every night with a snapshot first: security updates of WordPress (default), everything, or off.

Staging

Create a staging copy copies the site to staging.DOMAIN with its own database; search engines are told to stay away. Try updates and changes there; Push to live copies the staging site over the live one (after a snapshot of the live site), keeping the live wp-config.php.

Security

Always on: PHP files in uploads are not run, wp-config.php and hidden files are never served, password guessing on wp-login.php and xmlrpc.php is slowed down. Optional: block xmlrpc.php, debug output off, new security keys, the web application firewall of the website.
