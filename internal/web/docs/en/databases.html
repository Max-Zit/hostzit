Databases

Every account has its own MariaDB databases and database users; their names start with the account name (shop_wp). A database user can reach only the databases it is given.

Create

Under Databases, enter a name and keep with a user of the same name ticked: HostZit makes the database and a user with a strong password, shown once. Websites connect to localhost.

Users and passwords

Each user lists the databases it may use. Enter a new password or let HostZit generate one. Deleting a database removes it from all users.

Size

The size of each database is measured every 10 minutes and shown under Usage; it is counted separately from the disk space of the files.

Database manager

Open next to a database shows its tables, the rows page by page and the structure of each table; SQL runs any statements (at most 1000 rows per statement are shown, each stops after 30 seconds). Everything runs with rights on your own databases only. Export the database writes a gzip SQL dump into the folder backups; download it in Files.
