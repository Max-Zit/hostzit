Domains and DNS

HostZit runs authoritative name servers (PowerDNS). Zones of the customers are published within seconds of a change.

Zones

A zone is created with a new website (when asked) or under Domains and DNS. New zones get A/AAAA records for the domain and www, a CAA record for Let's Encrypt and the SPF record set by the administrator. To use them, enter the server's name servers at the domain registrar.

Records

The editor accepts A, AAAA, CNAME, MX, TXT, SRV, CAA, NS (delegation of a subdomain), TLSA, HTTPS, SVCB and PTR. Names are relative to the zone: @ for the domain itself, www, _dmarc. Values are checked before they are saved. Records managed by EmailZit are marked and cannot be changed here.

DNSSEC

Sign the zone switches DNSSEC on; put the DS record shown at the registrar. Before switching it off, remove the DS record at the registrar first.

Secondary name servers

Under Settings → Hosting, Secondary name servers holds the IP addresses of the name servers that copy every zone of this server, one per line (commas or spaces work too), for example:

198.51.100.53
203.0.113.77
192.0.2.10

Only these addresses may transfer the zones (AXFR), and each of them is notified of every change. Add every name server's name under Name servers as well (ns1, ns2, ns3 …) with glue records at the registrar.

DNS-only servers

Like cPanel's DNSOnly, the other name servers can be small Debian 12 or 13 servers that run only PowerDNS (1 CPU, 512 MB are enough). Adding one:

  1. Enter its IP address under Secondary name servers (one per line) and save.
  2. Run the command the page then shows on the new server as root — the same command on every DNS-only server, for example:
curl -fsSL https://github.com/Max-Zit/hostzit/releases/latest/download/install.sh | sudo bash -s -- --dns-only --primary 203.0.113.10 --catalog host1.example.com.catalog.invalid

A DNS-only server only receives: HostZit lists every zone in a catalog zone (RFC 9432) and the DNS-only server follows it, so new zones appear there within a minute and deleted zones disappear; changes of records arrive within seconds (NOTIFY). It sends nothing back to HostZit and only answers DNS queries from the internet.

Several HostZit servers, the same DNS servers: you do not need own name servers for every hosting server. Run the command of each HostZit server (its own address and catalog) on the same DNS-only servers and enter their addresses on each HostZit server. A domain must then exist on only one of the HostZit servers. The table under the command compares the serial of every zone on each secondary. In a Proxmox container switch on Nesting first.
